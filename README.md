# Referent

Референт - переводчик с ИИ-обработкой
PROJECT.md - описание проекта

## Локальный запуск

Требуются Node.js 22 и pnpm 10.24.0.

1. Выполните `pnpm install --frozen-lockfile`.
2. Создайте `.env.local` по образцу `env.example` и задайте ключ выбранного AI-провайдера. Не добавляйте `.env.local` в Git.
3. Выполните `pnpm dev` и откройте http://localhost:3000.

Для кнопки «О чем статья?» можно выбрать длину резюме: кратко, обычно или подробно. По умолчанию используется обычное резюме в 2–3 абзацах.

## Проверки

- `pnpm test` — проверка API резюме: три варианта длины, значение по умолчанию и отклонение неверных значений. Вызовы AI заменены заглушкой; ключи и платные запросы не нужны.
- `pnpm build` — production-сборка и проверка TypeScript.

GitHub Actions (`.github/workflows/ci.yml`) выполняет установку зависимостей из lock-файла, тесты и сборку при каждом push и создании или обновлении Pull Request. Результаты доступны во вкладке Actions и в проверках Pull Request. Секреты AI-провайдеров для CI не требуются.

Production в Vercel обновляется из `main`. Рабочую ветку проверяем через Preview и объединяем с `main` после успешных проверок.
